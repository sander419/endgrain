# Дорожная карта End-Grain Compiler

Здесь **фактическое** состояние инструмента, а не желаемое. Написано «сделано» —
работает и покрыто тестом; написано «ограничение» — инструмент говорит об этом
человеку сам, в том месте, где это важно. Проверить всё разом: `npm test`.

---

## Completed

### Проектирование
- Два режима: **Рецепт** (один щит, поперечный распил, перестановка планок)
  и **Мозаика** (рисунок по клеткам, под каждую уникальную колонку свой щит).
- 16 генеративных стилей в четырёх семействах, у каждого свои ручки
  (`GeneratorMeta.controls`) — мёртвых ползунков нет. `seed` даёт вариацию
  внутри стиля; у фракталов вариаций честно нет (`seeded: false`).
- 7 пресетов рецепта и «дикая доска» на seeded random (`random.ts`, mulberry32).
- Ручная правка: кисть по клеткам, перетаскивание планок мышью, переворот,
  сдвиг, обмен соседних. Отмена на 60 шагов (`useHistoryState.ts`).
- Свой текст (растеризация системным шрифтом, кириллица и латиница) и своё фото
  (кроп под пропорции доски, подбор ближайшей породы — `color.ts`).
- Избранное с миниатюрами в `localStorage` (`favorites.ts`).

### Расчёт
- Проекция рецепта в производство (`projection.ts`): число планок с учётом пропила,
  финальные размеры, сырой и чистый объём, board feet, потери, масса, себестоимость.
- Компилятор мозаики (`mosaic.ts`): уникальные колонки → щиты, зеркальные колонки
  берутся из одного щита.
- Разбор рисунка (`analysis.ts`): повторяющийся блок и симметрия → способ сборки.
- Движение древесины (`moisture.ts`): равновесная влажность по Hailwood–Horrobin
  (Wood Handbook гл. 4) и изменение размеров каждой породы (гл. 13).
  Пять контрольных точек справочной таблицы EMC закреплены тестом.
- Карта раскроя (`nesting.ts`): гильотинный first-fit, каждый рез съедает пропил,
  нетронутый хвост доски считается остатком, а не отходом.
- Экономика (`economics.ts`): время по этапам, полная себестоимость с трудом
  и накладными, цена продажи диапазоном.
- Профиль мастерской (`workshop.ts`): набор станков → порядок работ с обходными
  путями и честной оценкой, во сколько раз обходной путь дольше.
- «Столярный чек» (`validate.ts`): 11 замечаний — 7 для рецепта и 4 для мозаики,
  в одном виде и с одной разметкой. Каждое отвечает на четыре вопроса: что не так,
  почему, чем грозит, что сделать, — и ведёт в статью энциклопедии.
- **Готовность доски** (`readiness.ts`): один вердикт вместо россыпи замечаний —
  готово / есть замечания / не хватает данных / так не собрать, с причинами
  поимённо и указанием, где смотреть. Ничего не считает заново: сводит
  посчитанное замечаниями, набором станков, раскроем и справочником.
- Энциклопедия (`kb.ts`, `i18n/articles.ru.ts`): 10 статей о механизмах —
  движение древесины, усушка соседей, клеевой шов, струбцины, твёрдость,
  пропил, раскрой, рейсмус, контраст, уход. Тест держит инвариант КРУГа:
  у каждой ссылки есть живая статья.
- Контракт данных (`registry.ts`): каждое поле справочника помечено `source`,
  `est` или `unknown`. Цена и цвет — оценка навсегда: справочного значения
  у них не существует. В интерфейсе `est` показывается плашкой «оценка».
- Поиск по инструменту (`Ctrl+K`): вкладки обоих режимов, действия и статьи
  в одной строке.
- **Журнал факта** (`factlog.ts`): сколько ушло времени и материала на самом
  деле, множитель против расчёта и кнопка «принять как свой норматив».
  С пяти досок нормативы мастерской заменяют оценку для одиночки —
  и расчёт, партия и цена начинают считаться по её числам.

### Выпуск
- Печатная инструкция для мастерской: спецификация с припусками, шаги, схема
  переклейки, карта раскроя, материалы, чек-лист (`PrintSheet.tsx`,
  `MosaicPrintSheet.tsx`).
- Board DNA: весь проект в ссылке `#dna=`, без сервера и базы (`share.ts`,
  `mosaicShare.ts`).
- 3D-превью без three.js (`view3d.ts`, `render/board3d.ts`), экспорт PNG,
  режим снимка `?shot=1`.

### Безопасность
- Санитайзер чужой ссылки и `localStorage` (`sanitize.ts`): числа зажимаются
  в производственные пределы, цвет обязан быть `#rrggbb`, прототипные ключи
  не пускаются.
- CSP и политика реферера мета-тегами в прод-сборку (`vite.config.ts`).
- Прод-зависимостей две: `react`, `react-dom`.

### Продукт
- Проприетарная лицензия (`LICENSE`): бесплатная часть остаётся бесплатной,
  платный слой «Мастерская» открывается ключом.
- Механизм локализации (`core/i18n.ts`, `i18n/ru.ts`). Русский — единственный
  словарь; английский добавляется без переписывания кода.
- Офлайн-проверка ключа (`core/license.ts`): ECDSA P-256 через `crypto.subtle`,
  без бэкенда и без сети. Подделка тела, чужая пара, просроченный срок и мусор
  дают бесплатный режим и не роняют приложение. Запас на неверные часы — трое
  суток: компьютер в цеху вполне может отставать.
- Выпуск ключей (`tools/issue-license.mjs`): генерация пары, выпуск на срок
  или бессрочно, проверка выданного. Приватный ключ в репозиторий не попадает.
- Профиль мастерской (`core/profile.ts`): название, контакт, логотип, станки,
  ставки, покупная доска и склад одним объектом, с выгрузкой в файл и загрузкой
  обратно. Три прежних ключа `localStorage` читаются при первом запуске,
  поэтому обновление не обнуляет настроенное.
- Заказы (`core/order.ts`): клиент, срок, количество, согласованная цена,
  статус; доска хранится строкой Board DNA, архив выгружается одним файлом.
  Короткий код рецепта — четыре знака, которые можно продиктовать по телефону.
- Партия (`core/batch.ts`): время и деньги тиража, предельная стоимость ещё
  одной доски. Экономия времени — оценка из практики (`est`), экономия
  материала считается общим раскроем.
- Склад (`core/inventory.ts`): раскрой сначала по своим доскам, остальное —
  под покупку. Отвечает на вопрос «сколько **до**купить», а не «сколько купить».
- Документы клиенту: коммерческое предложение (`OfferSheet.tsx`) и паспорт
  изделия с уходом и номером рецепта (`PassportSheet.tsx`), оба под шапкой
  мастерской. Печатаются только для заказа, чья доска сейчас открыта.

## Next

Порядок — по тому, что раньше приводит мастерскую к потере денег.

1. **Английский словарь**, когда русский рынок покажет, что продукт покупают.

   способ получить пустой журнал.
3. **Косой рез** (30°, 45°, 60°): меняется вся геометрия планки и раскрой.

## Known limitations

Это не баги, а границы модели. Каждая проговорена в интерфейсе там, где важна.

- **Только прямой рез 90°.** Косые (30°, 45°, 60°) — отдельный модуль:
  меняется вся геометрия планки и раскрой.
- **Толщина всех брусков в щите одинаковая.** Разнотолщинный щит требует
  другой модели припусков.
- **Клеевые швы не считаются отдельным объёмом.** На толщине шва 0.1 мм
  и бруске 40 мм это 0.25% — ниже разброса самой древесины.
- **Раскрой гильотинный и жадный** (first-fit по убыванию): раскладка
  выполнимая, но не гарантированно оптимальная. Обрезки между полосами
  повторно не используются — только целый хвост доски.
- **3D-превью — превью формы, а не рендер.** Ортографическая камера, плоская
  заливка боковин, без освещения и теней.
- **Цена пород — рыночный ориентир, а не справочная величина** (`est`).
  Зависит от поставщика, сорта и партии; правится в интерфейсе.
- **Нормативы времени по умолчанию — оценка для мастерской-одиночки** (`est`),
  не измеренный факт. Журнал факта заменяет их измеренными, но множитель
  один на все операции: журнал знает общее время, а не время по операциям,
  и раскидывать его в придуманной пропорции значило бы выдать догадку за замер.
- **Движение древесины считается для свободного бруска.** В склеенном щите
  соседи держат друг друга, и реальное перемещение меньше расчётного;
  инструмент показывает верхнюю границу, а не прогноз.
- **Разрешение мозаики ограничено физикой.** Клетка — торец бруска 25–30 мм,
  поэтому 21 × 21 клетка это 525 мм. Фотографический пейзаж в таком масштабе
  не выйдет, силуэтный — выйдет.
- **Хранилище — этот браузер.** Ни сервера, ни синхронизации: закрытая вкладка
  помнит работу, чужой компьютер — нет. Профиль и архив заказов выгружаются
  файлом — это и есть перенос.
- **Экономия времени в партии — оценка** (`est`). Доли настроечной работы взяты
  из практики, норматива на них нет ни в одном справочнике. Числа осторожные:
  завысить экономию опаснее, чем занизить. Экономия материала, наоборот,
  считается общим раскроем.
- **Склад не смешивает породы и не оптимизирует по остаткам.** Доски берутся
  от больших к меньшим, каждая раскраивается тем же гильотинным алгоритмом.
  Раскладка выполнима, но не гарантированно лучшая из возможных.

## Deliberately not supported

- **Бэкенд, аккаунты, синхронизация, CRM, склад, магазин, мобильное приложение.**
  Инструмент считает изделие и производство одной мастерской, работает без сети
  и без чужого сервера — это и есть граница.
- **Защита от снятия проверки лицензии.** Исходники публичные; обфускация была бы
  самообманом, который стоит времени. Ключ — расписка, а не замок.
- **Новые генераторы узоров.** Шестнадцать — уже больше, чем мастерская
  использует за год. Следующая кнопка «ещё стиль» не добавит ни одной продажи.
- **Произвольная формула узора руками.** Всё считаемое в проекте проверяется
  тестом; формулу, введённую в поле, проверить нечем.
- **Рендер ради красоты.** Для КП нужен снимок формы и пород, а не фотореализм;
  фотореализм требовал бы three.js и трёх мегабайт бандла.

## Validation

```bash
npm test     # Vitest
npm run lint # oxlint
npm run build
```

КРУГ гоняет проверки отдельными скриптами `tools/check-*.mjs`, потому что там
ванильный JS без раннера. Здесь Vitest уже есть и уже стоит в CI — вторая система
запуска была бы вредом, поэтому смысл проверок КРУГа переносится в тесты.

| Тест | Что держит |
|---|---|
| `core.test.ts` | эталонный кейс: 9 планок, 360×160×40, отходы 22.96% |
| `moisture.test.ts` | пять контрольных точек таблицы EMC из Wood Handbook |
| `sanitize.test.ts` | чужая ссылка не вешает вкладку и не ходит на чужой сервер |
| `edge.test.ts` | NaN, Infinity, пустое поле, пределы ползунков |
| `mosaic.test.ts` | компилятор колонок: зеркальные колонки — один щит |
| `nesting.test.ts` | пропил съедает материал, хвост доски — остаток, не отход |
| `workshop.test.ts` | без станка шаг не исчезает, а получает обходной путь |
| `generators.test.ts` | у каждого стиля свои ручки, и все они на что-то влияют |
| `sources.test.ts` | породу без источника и с перепутанными колонками усушки не добавить |
